# Flashcards SmartApp Code scenario

Сценарий SmartApp Code для голосового управления Flash Cards через Салют.

## Как загрузить

1. Открой SmartApp Studio.
2. Создай или открой SmartApp Code проект.
3. Загрузи архив `flashcards-smartapp-code.zip` или содержимое этой папки.
4. Собери и опубликуй SmartApp Code.
5. Скопируй webhook опубликованного сценария.
6. В CanvasApp выбери сценарий `SmartApp Code API` и вставь webhook.

## Что отправляется во frontend

Сценарий отправляет команды через `smart_app_data`:

```json
{
  "type": "smart_app_data",
  "action": {
    "action_id": "start_topic",
    "parameters": {
      "number": 1,
      "topic_id": "english-vocabulary"
    }
  }
}
```

Frontend передает в Салют текущее состояние экрана: список тем, карточек или вариантов ответа. Поэтому команды вида `тема номер 1`, `карточка номер 2`, `вариант 3` привязываются к текущему экрану.

## Основные фразы

| Фраза | Действие |
| --- | --- |
| `покажи темы`, `на главную` | открыть библиотеку |
| `создай тему` | открыть форму создания темы, а на форме сохранить |
| `режим теста` | открыть тесты |
| `начни тему номер 1` | начать тренировку темы |
| `открой тему номер 1` | открыть тему |
| `тест по теме номер 1` | запустить тест |
| `редактировать тему номер 1` | открыть настройки личной темы |
| `удали тему номер 1`, затем `да` | удалить или скрыть тему |
| `название темы ...` | заполнить название темы |
| `описание темы ...` | заполнить описание темы |
| `включи автогенерацию`, `карточек 10` | настроить генерацию |
| `добавь карточку вопрос ... ответ ...` | добавить карточку в личную тему |
| `удали карточку номер 2` | удалить карточку |
| `ответ ...` | ответить на карточку в тренировке |
| `покажи ответ` | раскрыть текущую карточку |
| `знаю`, `дальше` | засчитать карточку как известную |
| `не запомнил`, `ошибка` | засчитать карточку как неизвестную |
| `вариант 1`, `первый` | выбрать ответ в тесте |
| `повторить тест` | перезапустить тест |
| `темная тема`, `светлая тема` | сменить оформление |

## События от frontend

Frontend отправляет `voice_feedback`, чтобы сценарий озвучивал ответы вроде `Правильно!`, `Карточка добавлена` или `Не нашла такую тему`.
Обработка находится в `src/sc/frontendEvents.sc`.
