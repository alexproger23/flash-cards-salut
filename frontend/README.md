
  # Minimalistic Flashcard Website

  This is a code bundle for Minimalistic Flashcard Website. The original project is available at https://www.figma.com/design/wrdaCceVfErFhsqJKlEuAf/Minimalistic-Flashcard-Website.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Salute voice

  Voice assistant support is integrated through `@salutejs/client`.
  Copy `.env.example` to `.env`, fill `VITE_SALUTE_TOKEN` and `VITE_SALUTE_SMARTAPP`, then restart `npm run dev`.

  SmartApp Code action format and supported commands are documented in `docs/salute-voice.md`.
